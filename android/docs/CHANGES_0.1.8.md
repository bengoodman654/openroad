# ClearRoute v0.1.8

- Rebuilt the map palette as dedicated OpenMapTiles layers so road, water and green-space colours no longer depend on Positron internal layer names.
- Enlarged the visual navigation alert into a strong peripheral amber/orange screen glow and added a Test edge flash button.
- Improved TTS selection by preferring a high-quality British-English local voice, with female-identifying voices preferred where the installed engine exposes that metadata.
- Added a shortcut to Android text-to-speech settings for installing/selecting voices.
- Navigation camera now zooms closer and places the current position lower on screen to show more road ahead.
- Current-position marker now includes a heading/course pointer.
