# ClearRoute v0.6.1

- Search now behaves as an attached live suggestion dropdown.
- The first search action is **Search current map area**, which constrains TomTom search to the visible map bounds.
- Area-search results are rendered directly on the map as labelled pins; tapping a pin opens the normal destination sheet.
- Suggestions are debounced while typing and biased by the existing search-location preference.
