# OpenRoad private transport server with app 0.6.17

OpenRoad 0.6.17 continues to use the already-deployed OpenRoad Transport Server v0.2.0. No server-side update is required for this app revision. The secure device-key pairing, HTTPS POST API, daily BODS timetable import and on-device fallback are unchanged.

If the server is already paired and reporting ready in OpenRoad, leave the cPanel deployment as it is.
