# ClearRoute v0.6.3

- Replaces the search-bar Start control with a star icon. Its menu shows Home first and all starred places underneath.
- Renames user-facing Saved-place wording to Starred places.
- Adds an easily accessible Along route control during active navigation.
- Along-route categories include service stations, petrol, supermarkets, food/coffee, rest stops, toilets and parking.
- Uses TomTom Along Route Search against only the remaining route geometry and shows detour information where available.
- Selecting an along-route result adds it as an intermediate stop while preserving the final destination. Automatic reroutes retain the pending stop until it is reached.
- Adds a Shazam item to the Along route sheet. It opens the installed official Shazam Android app while ClearRoute navigation continues in its foreground service. For one-tap recognition, enable Shazam's own “Shazam on app start” option.
- No new ClearRoute account, analytics, advertising or route-history storage.
