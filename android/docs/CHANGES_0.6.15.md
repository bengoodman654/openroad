# OpenRoad 0.6.17

- Added in-app public-transport navigation: Start now follows the selected journey stage by stage, showing walking/boarding/riding/alighting guidance, current-stage distance and scheduled arrival while tracking the phone on the coloured route.
- Restored Steps + Start controls for public-transport results.
- Integrated the route planner into the main Where to? search box. After Directions starts, the box shows the destination and a clear X; tapping the destination box opens My location / added stop(s) / destination / selected route.
- The route planner dropdown automatically closes while route results are being calculated or selected so it does not cover the map.
- Added one via stop for drive/cycle/walk routes and retained multiple public-transport via stops.
- Reworked the Directions and Transit icons for stronger legibility.
- Version and user-agent strings updated to 0.6.17.
