# OpenRoad 0.6.24 server requirement

OpenRoad 0.6.24 remains compatible with **OpenRoad Transport Server v0.2.2**.

No server deployment is required when upgrading the Android client from 0.6.23 to 0.6.24. The route-point ordering, bus-stop map layers, Places-sheet layout and Rail Data Marketplace live-departure authentication are client-side changes.
