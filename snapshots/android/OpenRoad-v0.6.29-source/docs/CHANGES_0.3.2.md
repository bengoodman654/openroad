# ClearRoute v0.3.2

- Rebuilt from the known-good v0.3.0 source after the v0.3.1 launcher-resource packaging problem.
- Uses the supplied navigation artwork as a properly cropped Android adaptive/mipmap launcher icon, removing the large white surround.
- Seeds the supplied personal TomTom API key into Android Keystore on first launch, while retaining the Settings option to replace it.
- Adds a native startup overlay and tap-to-retry fallback so a WebView startup failure is visible rather than presenting a silent blank screen.
- Fixes the ClearRoute palette version self-check to match the style generated by this build.
