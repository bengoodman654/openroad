# ClearRoute v0.6.2

- Removed the magnifying-glass search button; Enter confirms a full search.
- Added a compact Start button in the search bar. Its dropdown puts Home first and then offers saved destinations.
- Removed the separate Home/Saved quick chips from the map to reduce clutter.
- Added category-aware symbols to TomTom search suggestions and labelled map-area search pins (fuel, pubs/bars, cafes, food, shops, parking, health, rail, bus, airports, hotels, banking, parks and more where the result metadata identifies the type).
- Reworked Settings into four cleaner card-like groups: Places, Guidance, Map & location, and Routing & services. The Done control remains permanently fixed at the bottom.
- No server/proxy has been added: OpenFreeMap remains direct for best tile performance; the planned personal server remains reserved for roadworks/closure aggregation and optional API-key/privacy services.
