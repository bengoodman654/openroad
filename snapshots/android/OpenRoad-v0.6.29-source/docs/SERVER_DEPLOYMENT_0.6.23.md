# OpenRoad 0.6.23 server requirement

OpenRoad 0.6.23 remains compatible with **OpenRoad Transport Server v0.2.2**.

No server file or database update is required when upgrading the Android app from 0.6.22 to 0.6.23. The Android client now cancels stale route work more aggressively and requests the existing server `fast` phase first for individual segments of a public-transport journey with added stops.
